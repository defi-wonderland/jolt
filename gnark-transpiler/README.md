# Gnark Transpiler

Transpiles the Jolt verifier (stages 1-6) into gnark circuits for Groth16 proving.

## Prerequisites

The transpiler requires proof artifacts in `/tmp/`:
- `fib_proof.bin` - Serialized Jolt proof
- `fib_io_device.bin` - Serialized IO device
- `jolt_verifier_preprocessing.dat` - Verifier preprocessing data

These are generated by running the Jolt SDK's fibonacci example with proof serialization enabled.

## Usage

### 1. Run Transpilation

```bash
cd gnark-transpiler
cargo run --release
```

This generates:
- `go/stages16_circuit.go` - The gnark circuit
- `go/stages16_witness.json` - Witness data for testing

### 2. Run Groth16 Tests

```bash
cd go
go test -v -run TestStages16CircuitProveVerify -timeout 5m
```

This compiles the circuit, generates a Groth16 proof, and verifies it.

### Other Tests

```bash
# Just compile the circuit (fast)
go test -v -run TestStages16CircuitCompile

# Test constraint satisfaction (no proof generation)
go test -v -run TestStages16CircuitSolver
```

## Output

The full prove/verify test outputs:
- Constraints: ~1.5M
- Proof size: 164 bytes
- Prove time: ~5s
- Verify time: ~2ms
